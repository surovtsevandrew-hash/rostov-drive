# ROSTOV DRIVE

**Автор: Genz0, Андрей Суровцев**

Браузерный 3D-прототип по реальной географии Ростова-на-Дону. Это ранняя альфа, а не готовая игра.

## Первый запуск на Mac

Нужны Node.js 22+, Python 3 и Homebrew.

```bash
cd "$HOME/rostov-drive"
git pull --ff-only
bash scripts/prepare_world.sh
npm install
npm run dev
```

Открой http://localhost:5173.

Скрипт `prepare_world.sh` скачивает официальную выгрузку OpenStreetMap для Южного федерального округа от Geofabrik (примерно 300 МБ), извлекает геометрию центра Ростова и создаёт `public/world/center.json`. Исходные файлы сохраняются в `.data`; при повторном запуске скачивание не требуется.

Игра больше не обращается к публичным Overpass API из браузера. При отсутствии `center.json` показывается ошибка с командой подготовки данных вместо демонстрации вымышленного города.

## Реализовано

- Реальные контуры улиц и зданий OSM.
- Процедурные 3D-дороги, тротуары, фасады.
- Персонаж, автомобиль, простое управление WASD и мини-карта.
- Исправленное появление на дороге и старт камеры третьего лица.
- Инициализация Rapier и упрощённые коллизии зданий.

## Не реализовано

Физика колёс, GLB-анимации, NPC, задания, полный Ростов, многослойные мосты, точные коллизии, подтверждённые показатели FPS.
