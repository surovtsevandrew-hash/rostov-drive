# ROSTOV DRIVE 0.3 - рельеф реального Ростова

Автор: **Genz0, Андрей Суровцев**

Техническая альфа самостоятельной 3D-игры по OpenStreetMap и реальной цифровой модели рельефа. География, координаты и высоты основаны на реальных данных; фасады, балконы, витрины и городские декорации создаются процедурно и **не являются фотограмметрическими копиями Ростова**.

## Запуск на Mac

Требуются Node.js 22+, Python 3, Homebrew, osmium-tool.

Остановить старый Vite через Ctrl+C, затем:

```bash
cd "$HOME/rostov-drive" || exit 1
git pull --ff-only || exit 1
bash scripts/prepare_world.sh || exit 1
npm run build || exit 1
npm run dev
```

Открой http://localhost:5173.

**PBF Geofabrik повторно не скачивается**, если имеется `.data/south-fed-district.osm.pbf`. Подготовка заново создаст `public/world/center.json` по уже скачанной OSM-выгрузке, затем скачает и сохранит небольшие 256x256 высотные тайлы AWS/Mapzen в `.data/terrarium/`. Формируется `public/world/terrain.json`.

Без terrain.json проект честно показывает ошибку и не подменяет реальные высоты случайным рельефом. Для повторного запуска после успешной подготовки достаточно `npm run dev`.

## Новое в 0.3

- 225 × 161 точек высот на территорию расширенного Ростова.
- Terrarium DEM (порядка 10-30 м детализация источника в этом регионе, а не точные сантиметровые измерения).
- 3D-земля по географической высотной сетке.
- Подъёмы и спуски дорожного полотна и тротуаров по DEM.
- Фундаменты домов на средней высоте их контура.
- Машины, персонаж, пешеходы, деревья, светильники и камера расположены по отметкам поверхности.
- Дон и дорожки набережной привязаны к рельефу, вода визуализируется приближённой горизонтальной поверхностью.
- Дополнительные архитектурные элементы: балконы, ограждения, карнизы, уличные витрины, процедурные фактурные фасады.
- Метаданные OSM о материале фасада сохраняются там, где они реально указаны.
- Поддержка опциональных GLB-моделей персонажа и машины. Нет модели? Работает процедурный вариант.

## Ассеты CC0

В стандартный репозиторий крупные бинарные GLB **не загружены**. Их можно самостоятельно добавить в:
- `public/assets/characters/player.glb`
- `public/assets/vehicles/sedan.glb`

Официальные источники для скачивания и конвертации в GLB:
- Quaternius Universal Base Characters: https://quaternius.com/packs/universalbasecharacters.html
- Kenney Car Kit: https://kenney.nl/assets/car-kit
- Quaternius Universal Animation Library: https://quaternius.com/packs/universalanimationlibrary.html

Проверяй и сохраняй исходную лицензию конкретного пакета. Взятые из архивов модели приводятся к масштабу персонажа ~2.05 м и автомобиля ~1.74 м. Нужна соответствующая ориентация модели вперед по локальной -Z. Если в GLB есть анимационные клипы, загружается первый клип; полноценный граф переключения анимаций ещё не реализован.

## Управление

WASD - перемещение, E - сесть в машину, Shift - бег, мышь - обзор, колесо - расстояние камеры, 1 - центр, 2 - набережная.

## Ограничения

Высотные DEM-данные описывают землю, **не высоту проезжей части мостов и эстакад**. Точное моделирование мостов по вертикальным отметкам остаётся отдельным этапом. Некоторые низкие участки вдоль Дона потребуют ручной береговой коррекции. Здания имеют реальные OSM-контуры, но их архитектурная отделка правдоподобно генерируется, а не копирует каждый оригинальный дом. Полосы движения, физика подвески, сюжет и полноценная навигация NPC ещё не готовы.

Работоспособность этой версии на Mac должна быть подтверждена выполнением `npm run build` и запуском игры. Не считать успешную запись файлов в GitHub достаточной проверкой.
