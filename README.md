# ROSTOV DRIVE 0.2

Автор: **Genz0, Андрей Суровцев**

Браузерный 3D-прототип на настоящих данных OpenStreetMap. Это экспериментальная альфа, а не готовая GTA-подобная игра.

## Что изменилось в 0.2

- Район геоданных расширен с bbox 39.708–39.735 / 47.216–47.230 до 39.699–39.746 / 47.207–47.231, почти в 3 раза по площади.
- Извлекаются реальные улицы, здания, водоёмы, линии рек, парки и пешеходные дорожки.
- Дополнительные игровые объекты вдоль отображённых береговых/прогулочных маршрутов: лавочки, фонари, кусты.
- Процедурное отображение Дона по OSM-полигонам или линиям реки с приблизительной шириной, если точный берег отсутствует.
- До 24 движущихся машин NPC вдоль OSM-дорог и до 14 пешеходов вдоль реальных дорожек, если они есть в данных.
- Видимость зданий, окон, деревьев и фонарей управляется пространственными группами, чтобы большая карта не загружала GPU дальними объектами.
- Обновлены мини-карта и управление.

## Установка на Mac

Нужны Node.js 22+, Python 3, Homebrew, osmium-tool.

Останови предыдущий Vite через Ctrl+C.

```bash
cd "$HOME/rostov-drive" || exit 1
git pull --ff-only || exit 1
bash scripts/prepare_world.sh || exit 1
npm run build || exit 1
npm run dev
```

Открой http://localhost:5173.

**Скачивать 301 МБ PBF повторно не нужно:** скрипт использует `.data/south-fed-district.osm.pbf`, создаёт только новый `.data/rostov-expanded-v2.osm.pbf` и обновляет `public/world/center.json`. Первичная подготовка может занять несколько минут.

Ожидаемые поля вывода: `REAL_ROSTOV=YES`, `ROADS`, `BUILDINGS`, `PARKS`, `WATER`, `WATERWAYS`, `FOOTWAYS`, `WATERFRONT`, `DONE=YES`.

## Управление

- WASD - перемещение.
- E - сесть в машину / выйти.
- Shift - бег.
- 1 - переместиться к реальному участку дороги возле Большой Садовой.
- 2 - переместиться на реальную Береговую улицу (или ближайшую найденную дорогу у реки).
- Мышь - вращение камеры.
- Колесо мыши - масштаб камеры.

## Текущее состояние

Геометрия улиц и зданий основана на OSM. Внешний вид фасадов и детали набережной процедурные, не являются точной реконструкцией. Высота мостов и рельеф пока не моделируются, поэтому некоторые многоуровневые участки могут выглядеть неправильно. Автомобили NPC движутся по линиям дорог без полноценного соблюдения светофоров и полос.

Запуск, производительность и новая сборка должны быть отдельно проверены на Mac после обновления. GitHub Actions в этом репозитории пока не подтвердил успешную сборку.
